FASE 1 — ANÁLISIS DEL PROYECTO

Antes de escribir código deben:

1. Leer todos los archivos TXT de la carpeta.

2. Crear una comprensión completa del producto.

3. Identificar:

- Objetivo del producto.
- Usuarios del sistema.
- Funcionalidades principales.
- Módulos existentes.
- Dependencias entre módulos.
- Riesgos técnicos.
- Decisiones pendientes.
- Información faltante.

4. Crear un documento llamado:

"TCG Vision — Technical Analysis Report"

Debe incluir:

- Resumen ejecutivo.
- Arquitectura propuesta.
- Stack tecnológico recomendado.
- Modelo de negocio entendido.
- Flujo completo del usuario.
- Flujo administrativo.
- Flujo de publicación de cartas.
- Flujo de assets.
- Flujo ecommerce.
- Riesgos.


NO IMPLEMENTEN CÓDIGO TODAVÍA.

FASE 5 — METODOLOGÍA DE TRABAJO

Trabajaremos como una empresa real.

Reglas:

1. No avanzar sin cerrar el sprint actual.

2. Antes de implementar explicar:

- Por qué.
- Archivos afectados.

3. Cada entrega debe incluir:

- Código.
- Explicación.
- Cómo probarlo.
- Próximos pasos.

4. Priorizar:
- Calidad.
- Seguridad.
- Escalabilidad.
- Mantenibilidad.
