PARTE 3 — ADMIN PANEL & STUDIO SPECIFICATION
Objetivo
Definir la herramienta administrativa interna del sistema TCG Vision.

El Admin Panel & Studio será el centro de control utilizado para crear, editar, organizar, personalizar y publicar cartas digitales del catálogo.

El objetivo principal es permitir que un administrador pueda gestionar todo el ciclo de vida de una carta:

Creación
   ↓
Carga de Assets
   ↓
Configuración de Datos
   ↓
Aplicación de Rareza y Efectos
   ↓
Vista Previa
   ↓
Publicación
El Studio debe funcionar como una herramienta similar a un CMS especializado para cartas coleccionables, permitiendo controlar tanto información estructurada como elementos visuales.

1. Alcance del Admin Panel
El panel administrativo permitirá:

Crear cartas nuevas.

Editar cartas existentes.

Administrar colecciones.

Administrar categorías.

Configurar rarezas.

Aplicar efectos visuales.

Gestionar imágenes.

Preparar cartas para publicación.

Controlar estados del catálogo.

Revisar previews antes de publicar.

2. Usuarios del Sistema Administrativo
2.1 Administrador
Usuario con control total.

Permisos:

Crear cartas.

Editar cualquier información.

Gestionar usuarios.

Publicar contenido.

Configurar parámetros globales.

2.2 Editor de Contenido
Usuario encargado del catálogo.

Permisos:

Crear cartas.

Modificar información.

Subir imágenes.

Editar colecciones.

No puede:

Modificar configuración del sistema.

Administrar usuarios.

2.3 Diseñador Visual
Usuario enfocado en presentación.

Permisos:

Subir assets.

Aplicar efectos.

Configurar frames.

Crear previews.
