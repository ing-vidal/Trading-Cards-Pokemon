TCG Vision — Complete Development Documentation
1. Objetivo del Sistema
Esta sección define la arquitectura técnica necesaria para llevar TCG Vision desde un entorno de desarrollo hasta producción.

El objetivo es crear una plataforma escalable capaz de:

Administrar cartas coleccionables digitales.

Gestionar imágenes, modelos 3D, efectos visuales y recursos multimedia.

Publicar un catálogo público.

Permitir visualización avanzada de cartas.

Administrar usuarios internos.

Preparar integraciones comerciales.

Mantener seguridad, rendimiento y escalabilidad.

La arquitectura debe permitir crecimiento futuro:

Más colecciones.

Miles de cartas.

Nuevos tipos de rareza.

Nuevos efectos visuales.

Nuevos canales de venta.

Aplicaciones móviles.

Integraciones externas.

6. API REST Specification
Base URL:

https://api.tcgvision.com/v1
Authentication
POST
/auth/login
Request:

{
 "email":"admin@test.com",
 "password":"123456"
}
Response:

{
 "access_token":"jwt_token",
 "refresh_token":"token"
}
Users API
Obtener usuarios
GET /users
Crear usuario
POST /users
Actualizar usuario
PATCH /users/{id}
Cards API
Listar cartas
GET /cards
Filtros:

?page=1
&rarity=gold
&collection=dragon
&status=published
Crear carta
POST /cards
Obtener carta
GET /cards/{id}
Actualizar carta
PATCH /cards/{id}
Publicar carta
POST /cards/{id}/publish
Eliminar carta
DELETE /cards/{id}
Collections API
GET /collections
POST /collections
PATCH /collections/{id}
DELETE /collections/{id}
Rarity API
GET /rarities
POST /rarities
PATCH /rarities/{id}
Effects API
GET /effects
POST /effects
PATCH /effects/{id}
Assets API
Subir archivo:

POST /assets/upload
Request:

multipart/form-data
Response:

{
"url":"storage/image001.png"
}
Products API
GET /products

POST /products

PATCH /products/{id}
Public Catalog API
Sin autenticación.

Obtener catálogo
GET /public/cards
Detalle carta
GET /public/cards/{slug}
